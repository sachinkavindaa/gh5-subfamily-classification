# GH5 Subfamily Classification and Analysis

## Project Title
**Subfamily Classification and Analysis of CAZy Family GH5**

## Project Goal

The main goal of this project is to classify the **GH5 CAZy family** into subfamilies, then analyze and visualize the results using modern bioinformatics approaches.

GH5 is a large and diverse glycoside hydrolase family with many enzyme functions. Subfamily classification helps group similar proteins and better understand their biological roles.

## About This Project

In this tutorial, **GH5 family proteins** were used to explain how bioinformatics tools can be applied for:

- protein family classification  
- sequence analysis  
- network analysis  
- phylogenetic analysis  
- functional interpretation  
- biological visualization  

This project includes scripts, workflow files, notes, and presentation materials.

## Workflow Overview

The main steps used in this project are:

1. Dataset collection and preprocessing  
2. Domain annotation using HMMER and dbCAN  
3. Extraction of protein modules based on annotations  
4. Construction of Sequence Similarity Networks (SSN)  
5. SSN analysis using characterized proteins and EC numbers  
6. Network visualization using Cytoscape  
7. Phylogenetic tree analysis  
8. Result interpretation and discussion
